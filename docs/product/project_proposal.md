# Campus AI Agent 项目说明

## 一、项目背景

大学生日常学习和校园生活中，经常需要查询课程安排、校园活动、学校制度、考试要求、奖学金政策以及个人学习规划等信息。

但在真实校园场景中，这些信息通常分散在多个系统和渠道中，例如教务系统、学院官网、通知公告、学生手册、微信群、课程群和辅导员通知等。学生在查询信息时，往往需要反复切换平台，搜索成本较高，也容易遗漏重要信息。

与此同时，传统聊天机器人通常只能进行通用问答，无法稳定调用结构化工具，也无法基于校园制度文档给出可靠回答。因此，本项目希望基于 AI Agent 技术，构建一个面向大学生校园场景的智能助理系统，让学生可以通过自然语言完成课程查询、活动查询、制度问答和学习计划生成等任务。

## 二、项目名称

Campus AI Agent 校园智能助理

## 三、目标用户

本项目的核心用户是大学生，尤其适合以下场景：

1. 需要快速查询课程安排的学生；
2. 想了解近期校园活动、讲座、比赛的学生；
3. 需要查询请假、奖学金、宿舍、考试等校园制度的学生；
4. 正在准备实习、竞赛、考研或课程学习计划的学生；
5. 希望通过聊天方式统一获取校园信息的学生。

## 四、项目目标

本项目基于 Agent Service Toolkit 进行二次开发，构建一个具有校园业务场景的 AI Agent 应用。

项目目标不是简单调用大模型完成聊天，而是实现一个包含 Agent 编排、工具调用、RAG 检索问答、前后端交互和工程化部署能力的完整 AI Agent 系统。

最终希望实现：

1. 用户可以通过 Streamlit 聊天页面输入自然语言问题；
2. 前端通过 client 调用 FastAPI 后端服务；
3. 后端由 Agent 判断用户意图；
4. 对于课程、活动、学习计划等问题，Agent 调用对应工具；
5. 对于校园制度类问题，Agent 优先基于知识库进行 RAG 检索问答；
6. 系统能够返回结构清晰、面向学生场景的回答；
7. 项目具备 README、测试、Docker 和面试展示材料。

## 五、核心功能

### 1. 课程表查询

用户可以通过自然语言查询课程安排，例如：

- 我今天有哪些课？
- 我周一上午有什么课？
- 数据结构课在哪里上？
- 明天下午有没有课？

系统后续会通过本地 mock 数据或结构化课程表数据，调用课程查询工具返回课程名称、时间、地点、教师和备注。

### 2. 校园活动查询

用户可以查询近期校园活动、讲座、比赛、社团活动等信息，例如：

- 这周有什么活动？
- 有没有 AI 相关讲座？
- 最近有什么适合软件工程学生参加的活动？
- 有什么比赛可以报名？

系统后续会通过校园活动工具，根据关键词、活动类型和时间范围进行查询。

### 3. 校园制度 RAG 问答

用户可以询问学校制度相关问题，例如：

- 请假流程是什么？
- 挂科后还能评奖学金吗？
- 宿舍晚归有什么规定？
- 考试作弊会有什么后果？
- 生病缺考应该怎么办？

系统后续会基于校园知识库文档进行检索增强生成，回答时需要尽量给出依据、流程、注意事项和来源文档，避免模型凭空编造。

### 4. 学习计划生成

用户可以让系统根据目标生成学习计划，例如：

- 我一个月后要面试 AI Agent 岗位，帮我制定学习计划。
- 我今天没课，帮我安排今天的学习。
- 结合我的课程表，帮我规划本周学习。
- 帮我制定一份 7 天 Python 复习计划。

系统后续会结合用户目标、课程安排、空闲时间和学习主题，生成结构化学习计划。

### 5. 文件问答

后续可以扩展文件上传问答能力，允许用户上传课程资料、通知文件或学生手册，然后围绕文件内容进行问答。

该功能不是 Day 5 阶段的重点，可以作为后续优化方向。
